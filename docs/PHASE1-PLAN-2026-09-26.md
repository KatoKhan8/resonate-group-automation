## WHAT THE AUDIT CHANGES ABOUT THIS PLAN

Three findings move work off the list before it starts.

**1. No new store. `productive.yaml` is canonical and stays canonical.**
The audit confirms `clients.load()` is what `generate.py`, `bisonfactory.py`,
`heyreachfactory.py`, `copyprompts.py` and `copystages.py` all read. A parallel
store would be the wrong build. **The Second Brain is a RETRIEVAL LAYER over
what exists, not a database.**

**2. `contextpack.py` already is most of the Second Brain, and nothing reads
it.** 590 lines assembling segments, priority, signals, strategy and claims -
consumed only by `src/web/api.py`. It is a display module. Phase 1 makes it a
workflow input. That is integration, not construction.

**3. The HeyReach cadence is NOT broken.** The "one step from six" measurement
is stale. `heyreachfactory._refuse_missing()` now refuses the entire staging
when a required role lacks approved copy, and `PRODUCTIVE_LI_HEAVY_V1` carries
five LinkedIn steps and five email steps, all populated. **TASK-314 still ships
the regression test** so a future change cannot reintroduce silent dropping,
but no repair is needed.

## TASK-317 — the Client Second Brain as retrieval, not a store

**Depends on:** nothing. **Start first.**

### Files

    src/secondbrain.py        NEW. The retrieval layer.
    src/contextpack.py        MODIFY. Becomes a workflow input.
    config/clients/productive.yaml   READ ONLY. Never duplicated.
    src/clients.py            READ. Already the loader.
    src/playbooks.py          READ. Existing playbook architecture.
    tests/test_the_second_brain_returns_only_what_the_task_needs.py  NEW

### Build

`secondbrain.for_task(task, client, **scope)` returns **only the sections that
task needs**, each fact carrying `source` and `date`. Sections map to spec §3:
profile, market, customers, messaging, offers, learning. Competitor
intelligence is declared MISSING rather than invented.

**The whole Second Brain is never passed into a prompt.** The spec says so and
the cost shape depends on it: `COHORT_SYSTEM` is 936 cached tokens and the
per-lead turn is 61. A retrieval layer that returns everything would undo that.

Every fact answers three questions or it is not returned: where did it come
from, when, and is it verified or inferred.

### Index page

`work/review/secondbrain-<client>.html`, the ten sections from spec §3, plus
**MISSING INFORMATION AND RESEARCH PRIORITIES** as a first-class section -
that is where competitor intelligence, case studies and offers appear until
the client supplies them.

### Acceptance

    py -3 -c "import sys;sys.path.insert(0,'.');from src import secondbrain as b;\
    r=b.for_task('cold_email_writing','productive');\
    assert 'market' not in r, 'returned a section this task does not need';\
    assert all(f.get('source') and f.get('date') for f in r.get('facts',[]));\
    print(sorted(r))"

plus a test proving two different tasks get different sections, and that no
fact is returned without a source and a date.

### Risk and rollback

Risk: it becomes a second source of truth by accident. **Mitigation: it may
only READ `productive.yaml` and the existing modules; a test asserts
`secondbrain` writes no client facts anywhere.** Rollback: delete the module;
nothing else changes, because it is additive.

## TASK-318 — the Offer Engine, with the gaps listed rather than invented

**Depends on:** TASK-317.

### Files

    src/offers.py                          NEW
    config/clients/productive-offers.yaml  NEW. Offers only, approval-gated.
    src/secondbrain.py                     MODIFY. Serve the offer section.
    tests/test_an_offer_cannot_be_invented.py  NEW

### Build

The schema from spec §3E: offer id, segment, persona, business problem, value
proposition, **concrete deliverable**, supporting evidence, CTA, conditions,
approval status, version, campaigns using it.

**Ships with the six confirmed capabilities and NOTHING ELSE.** `project_management`,
`time_tracking`, `budgeting`, `resource_planning`, `billing`, `profitability`,
in the client's own words from `product.capabilities`.

**Two offers per campaign where approved terms exist. Where they do not, the
campaign carries one offer and the gap is listed.** A campaign is not blocked
for want of a second offer; it is honest about having one.

`offers.missing()` returns everything the client must supply. **Seeded from
what is already known to be absent:** no customer case studies, no verified
benchmarks, no dashboard or workflow example, no calculator, no demo link.

### The rule that matters

**An offer with `approval_status != "approved"` cannot reach copy generation.**
Not a warning. A refusal, in the same shape as `reviewapproval`: production
does not approve its own offers.

### Acceptance

    py -3 -c "import sys;sys.path.insert(0,'.');from src import offers;\
    import traceback;\
    ok=False;\
    exec('try:\n offers.for_campaign(503, require_approved=True)\nexcept offers.NotApproved:\n ok=True');\
    assert ok, 'an unapproved offer reached a campaign';\
    print(len(offers.missing()),'gaps listed for the operator')"

### Risk and rollback

Risk: a model invents a deliverable or a commercial term. **Mitigation: offers
are data, never generated; the writer receives an offer id and the client's own
sentence.** A test asserts no LLM call can create an offer. Rollback: the
engine is additive; unwiring it returns the writer to capability-only copy.

## TASK-320 — campaign-first strategy

**Depends on:** TASK-318, TASK-319.

### Files

    src/campaignstrategy.py    NEW or EXTEND if a strategy module exists
    src/copystages.py          READ. Stage E moves from per-lead to per-segment.
    src/segments.py            READ. Existing segmentation.
    tests/test_strategy_is_set_per_segment_not_per_lead.py  NEW

### Build

**Strategy and offers are decided ONCE PER SEGMENT.** Per-lead work adapts
them: ICP, account research, signal relevance, personalisation, validation.

This is the spec's core principle and it is also the cost argument. Stage E
currently runs per lead. At 50 leads in one segment that is 49 redundant calls.

Strategy carries: target ICP, segment, persona, primary problem, primary offer,
secondary offer, evidence, approved angles, objective, CTA strategy,
disqualification criteria.

### Acceptance

    py -3 -c "import sys;sys.path.insert(0,'.');from src import campaignstrategy as c;\
    a=c.for_segment('US-East/MktgAdv','economic_buyer');\
    b=c.for_segment('US-East/MktgAdv','economic_buyer');\
    assert a['strategy_id']==b['strategy_id'], 'strategy regenerated per call';\
    print(a['strategy_id'])"

plus a measured count: strategy calls per 50-lead batch. **It must be 1 per
segment, not 50.**

**Depends on:** TASK-320. **This closes the audit's Bug 4 and Bug 5.**

### Build

`copypath.py` goes B -> **C -> D -> E -> F** -> lint -> **sequencegate** ->
stage. `bisonfactory` calls `sequencegate.check` before it stages, and **a
failure refuses the staging naming the step**, exactly as `reviewapproval`
refuses activation.

### The test that makes this permanent

    tests/test_every_stage_has_a_production_caller.py

walks the import graph and **fails if any module in `copystages`,
`sequencegate`, `secondbrain`, `offers` or `skills` has no non-test caller.**
The audit found five disconnected modules; this test makes a sixth impossible
to merge.

### Acceptance

    py -3 -m unittest tests.test_every_stage_has_a_production_caller

and:

    py -3 -c "import sys;sys.path.insert(0,'.');import ast,pathlib;\
    src=' '.join(p.read_text(encoding='utf-8') for p in pathlib.Path('src').rglob('*.py'));\
    assert 'copystages' in src and 'sequencegate' in src;\
    print('both wired')"

### Risk and rollback

**This is the highest-risk task in phase 1** because it changes the path that
produces prospect-facing copy. Mitigation: it is additive to a pipeline that
already refuses on `copylint`; `sequencegate` failures refuse rather than
regenerate; and the ten and the fifty are produced by the direct scripts, which
are untouched. **Rollback: revert one commit in `copypath.py`;** the stage
modules are read-only in this task and do not change.

told `productive.yaml` is canonical, and 317 carries a test that
`secondbrain` writes no client facts.

**Scope creep into phase 2.** Person-relevance, semantic repetition,
retargeting and the learning loop are NOT in phase 1. The audit lists them as
recommendations, not bugs. Building them now delays the thing that pays: better
copy on the fifty.

**The copy path changing under tonight's deliverables.** 321 touches
`copypath.py`. The ten and the fifty run from `work/v2_run.py`, which does not
import it. Verified, not assumed.

**An invented offer reaching a prospect.** The reason offers are data and the
approval refusal is mechanical.
